# 🛍️ Customer Trends Data Analysis

## 📌 Project Overview

The **Customer Shopping Behavior Analysis** project focuses on analyzing customer purchasing patterns and shopping preferences to uncover meaningful business insights.

Using **Python, SQL, and Power BI**, this project explores customer shopping data to understand purchasing behavior, identify trends, evaluate product performance, and generate actionable insights through an interactive dashboard.

The primary objective is to help businesses better understand their customers, optimize marketing strategies, and make informed, data-driven decisions.

## 🎯 Project Objectives

- Analyze customer shopping behavior and purchasing patterns.
- Understand customer preferences across different product categories.
- Identify trends in customer spending and purchase frequency.
- Explore relationships between customer demographics and shopping decisions.
- Perform data cleaning, exploratory analysis, and SQL-based data analysis.
- Develop an interactive Power BI dashboard to visualize key business insights.

## 🚀 How to Run the Project

### 1. Clone the Repository

```bash
git clone https://github.com/Rahul8800Kumar/Customer-Trends-Data-Analysis.git
```

### 2. Navigate to the Project Directory

```bash
cd Customer-Trends-Data-Analysis
```

### 3. Install the Required Python Libraries

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

### 4. Launch Jupyter Notebook

```bash
jupyter notebook
```

Open `Customer_Shopping_Behavior_Analysis.ipynb` and execute the notebook cells.

### 5. Run SQL Queries

Open `customer_behavior_sql_queries.sql` using SQL Server Management Studio (SSMS) and execute the queries against your dataset.

### 6. Explore the Power BI Dashboard

Open `customer_behavior_dashboard.pbix` using Microsoft Power BI Desktop to explore the interactive visualizations and business insights.
